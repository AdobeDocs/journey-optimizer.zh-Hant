# 互動式示範 {#loyalty-challenges-demo}

在圍繞Adobe虛構的生活方式零售品牌「Luma」建立的自我引導式、可點按的示範中，檢視行動中的忠誠度挑戰。

此示範涵蓋三個流程：行銷人員的挑戰建立體驗（包括自攜資料挑戰以及效能和見解儀表板）、最終客戶的體驗，以及CX Coworker中的忠誠度挑戰管理。

按一下任何畫面左上方的Luma標誌或產品名稱，以切換流程。
